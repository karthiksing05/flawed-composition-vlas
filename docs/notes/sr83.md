## 83. A2 distributedness probe: activation patching and band ablation on frozen pi0.5 and RAA-sL (ledger row m3_prereg__libero_goal__a2__s0__11a2af49.json, written before any main capture or probe; plan docs/notes/a2_plan.md, predictions experiments/prereg/a2_pred.txt)

**Question.** Paper section 4.8 / 6 ([A2] "a mechanistic probe per failure is to run"; PLAN_PAPER W2).  In frozen pi0.5 (pi05_libero) is the computation that binds the instruction's role word to a scene entity distributed over many components, with band ablations unselective across F7 / N / K?  In RAA-sL (pi05_g8v_raas_l_ae main6000, SR 82) is the same binding localised in the role channel (4-dim state token + servo)?  Open loop: the models are run on recorded model inputs, nothing is executed.

**Design as run.**
* Recorded inputs (experiments/a2_capture.py: the dict GuidedPolicy.infer receives, i.e. after the role views, paint and channel, plus the noise seed it drew and the chunk it returned; experiments/a2_cap_client.py = steer_probe.py with the SR 83 capture rule).  Hold-phase observations did not exist in the repo (results keep start states and chunk displacements), so each model was rolled closed loop on the SR 70-82 dev states up to the hold and the model input was recorded there (deviation 1).  N / K (n2_goal, n2_branches_main = trials 4-23, max 240 steps): the 3rd held query of each episode; at it one side query per swap candidate (target phrase swapped; RAA-sL: the whole front end for the swapped instruction), then the real query.  Tasks K1, K2, K4, K6 (tids 0, 2, 6, 10), N1, N4, N5, N6 (tids 16, 22, 24, 26).  F7 (rg_comp states, trials 4-23, first 20 of br7_main = results/flawed/a2/br7_a2.json): row 0 of rgc tid 0 (left bowl) and 1 (right bowl); SP_R is SP_L with the bowls swapped, so the counterfactual of a state is the other task's instruction on the same layout (pi0.5: the clean input with the partner's prompt; RAA-sL: the partner task's recorded input through wa_s.py full).  Selection in the probe (registered): per N / K task the first 12 captured episodes in trial order with a swap candidate whose prompt has the clean prompt's token count.  Captured: 318 of 320 episodes had a 3rd held query.
* Observations used: pi0.5 F7 40 (20 layouts x 2 instructions), N 48, K 36 (K4 has no equal-length candidate in pi0.5's whole-sentence prompts: "on top of the cabinet" is 5 tokens against 3; 20 skipped, listed in results/flawed/a2/probe_pi05_K/selection_K.json); RAA-sL F7 40, N 48, K 48 (role phrases have no preposition, K4 present).
* Probe (experiments/a2_probe.py, hooks on the served model, backbone.py untouched): per observation 233 (pi0.5) / 241 (RAA-sL) runs in batches of 19 + a clean reference row, one noise draw (the seed the server drew) shared by clean, counterfactual and all patched runs.  Writes (attn / mlp sublayer outputs) of the 18 VLM layers and 18 action-expert layers at all positions (the 72 registered components U1), the VLM writes at the instruction tokens, residual-stream patches, 48 heads (layers 3 / 9 / 15), RAA-sL: in.prefix / in.tok / in.servo / in.chan; ablations on the clean run: VLM bands 0-3 / 4-8 / 9-13 / 14-17 (all positions and instruction positions), expert bands 0-8 / 9-17, RAA-sL channel / token / servo removed.
* Effect: s_cf = (sum of the first 5 xyz deltas of the unnormalised chunk) . unit(end effector -> counterfactual entity); s_cor toward the entity the clean instruction names.  Statistics, labels, bootstrap (B = 2000, rng 0, clusters within set, 95% percentile CIs) exactly as in a2_read.py's docstring.  Plumbing: the open-loop replay of the served chunk differs by .0013-.0166 over the 260 observations (median .0035, 90th percentile .0069; four of six probe sets have a maximum above .01; bf16 and batch noise); identity patches (smoke, 5 observations per model, plumbing numbers only) .001-.006.

**Descriptive (not registered).**
* Cumulative residual patch (VLM residual stream at layer L, all positions, from the counterfactual run; pooled mean effect, T 1.66 in pi0.5): 1.66 at layers 0-5, 1.53 at 12, 1.21 at 13, **.10 at 14**, 0 at 17. In both models the prefix information the action expert uses is read from the keys / values of prefix layer 14 (the K / V computed from the layer-13 output carry about two thirds of pi0.5's total and nine tenths of RAA-sL's prefix-borne effect).  The layer writes that produce it are spread (top1 .19), the read site is not: a distributed write, a narrow read.  This agrees with the KV_14 component of the earlier purification work (PARTS).
* RAA-sL's role channel: the 4-dim state token alone moves nothing (token patch -.007, token ablation -.01 on every set: the trained expert does not read the state token's value); the servo input alone carries the whole channel effect (.878 pooled, .995 on N, .846 on K) and is exactly zero before the hold, so the F7 (grasp-phase) binding is in the prefix (in.prefix 1.017, i.e. the painted views and role prompt) and the VLM bands 4-8 / 9-13 (SELECTIVE for F7: drop .95 / .50 against .12 / .14 on K).  Channel removal ablates K as much as N (drop .98 against 1.21, sel .23 [.04, .44]).  The registered "localised in the channel" holds in the sense that removing the channel removes the held-target steering (relative drop 1.0-1.2 on N and K), through a fixed linear servo function, not a learned token.

**Answer.**  Half of the claim is borne out by the registered statistics.  In pi0.5 no single write carries the target binding: the largest of the 72 layer writes holds .19 [.17, .21] of the positive single-component effect (top3 .48), expert layers 14 and 17 attention and VLM layer 12 attention the largest, and no band ablation is SELECTIVE for the failure sets, but the participation ratio sits at .155 [.133, .185], under the registered .2, so the registered "distributed" form is not met; the profile also has a narrow read site at prefix layer 14.  In RAA-sL the binding is localised in the role channel where the target matters: chan_share .871 [.834, .914] (SUPPORTED; N .987, K .841), through the servo, not the state token; the F7 object-binding is in the prefix, not the channel (chan_share -.006), and removing the channel ablates K nearly as much as N (sel .23 [.04, .44], NOT SELECTIVE).  The write-level statistics of RAA-sL (top1 .18, PRn .20) look as diffuse as pi0.5's: the localisation is in a component outside the 72 writes, so the two models are not separated by U1 statistics.

**Deviations.** (1) Hold-phase observations did not exist; the capture re-ran each model closed loop on the dev states until the 3rd held query (the instruction said no closed-loop rollouts were needed); the N / K episodes executed to 240 steps, nothing else was run closed loop.  (2) F7 positions come from results/flawed/rg_comp/cache_f7.pkl (layout cache, not re-measured at row 0); the end effector from the pi0.5 capture's state for both models.  (3) K4 has no equal-token swap candidate for pi0.5, so pi0.5's K is 36 observations on 3 tasks against RAA-sL's 48 on 4; the K4-free RAA-sL read is the sensitivity.  (4) The first smoke-probe submission failed on argument parsing (sbatch --export splits on commas): lists in a2_probe.py / a2_read.py use "+" instead, fixed before the prereg row.  (5) experiments/a2_read_sens.py was added after the row (descriptive; a2_read.py is unchanged and imported).  (6) A command that contained a stray `python3 -c 1` line was refused by the permission layer and executed nothing; an attempted read of the smoke outputs with a2_read.py was refused and not retried (the read code path was tested on synthetic observations instead, a2_read.py selftest, including the full analysis).  (7) The smoke capture record of one K1 pi0.5 episode (d5 values of the true and three counterfactual chunks) was printed once while checking the plumbing; recorded in the row's "seen".  (8) Probe jobs were queued with afterok dependencies on the captures before the captures ran.  (9) The two uncaptured episodes (of 320) are those without a 3rd held query.  (10) Ledger row written by the existing prereg path, tree dirty with foreign uncommitted edits.

**Limits.** One noise draw per observation; patched-vs-reference differences of .002-.007 are bf16 / batch noise, the effects read here are 100 times larger.  Expert-layer patches at denoising steps after the first import the counterfactual trajectory's x_t through the replaced activation, so single-component effects can exceed T (coverage 2.13 in pi0.5: single writes are super-additive; negative effects such as exp.1.mlp -.80 are of that kind), and the sum of positive effects is not a decomposition of T.  The relative-drop selectivity divides by the intact displacement: on F7 for pi0.5 (intact .36) and for the INVERSE cells it blows up (-2.5, -3.3); the absolute displacements are in the json (a2_read_*.json stats abl.*).  Zero-ablation of a band damages every set; the matrices are read against K.  F7 for pi0.5 is a set on which the instruction word has no effect (UNTESTABLE), so every pi0.5 selectivity cell on F7 is a cell on a set the model does not steer; N for pi0.5 is n/i.  Two models, one scene family, pick-place tasks, LIBERO; RAA-sL's servo is a fixed hand-set function of the channel, so "localised in the channel" is also "localised in a component designed to carry it".  The RAA-sL F7 pairing uses the partner task's front-end output (resolver, paint, channel) as its counterfactual.
