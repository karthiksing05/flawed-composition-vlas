# Compositional-generalisation evaluation of robot policies / VLAs: novelty check for MCD-style, depth-stratified binding splits

Method note: "[full text]" means the arXiv HTML (or ar5iv) full paper was fetched and read through a summariser that answered targeted questions. Long papers were sometimes read only up to about the first 100k characters, and those are flagged "[full text, partial]". "[abstract/snippet]" means only the abstract or search snippets were seen. Search window: through 2026-10-27.

## Q1. How existing benchmarks build compositional splits: is compound divergence measured or controlled, is referring depth or sub-region a factor, and which models are tested?

### Takeaway
None of the 17 benchmarks or papers read builds MCD-style splits, i.e. splits with atom divergence held fixed and compound divergence measured, controlled or binned. None stratifies by referring-expression depth (type / instance / relational sub-region). The closest designs are (a) held-out pairings with every atom covered (Spa-Bench withheld cells, the 2602.24143 object x region split, the 2607.21582 diagonal-train / off-diagonal-test split, CompoSuite, VIMA L2), and (b) the 2607.29687 count of seen instruction pairs ("pairwise coverage"), which tracks OOD success. Both are coarse proxies for compound divergence, and neither is graded the way MCD is. Keysers et al. is cited in exactly one robot paper (2607.21582), and only in related work.

### Cited Findings
Per-paper findings. CD = compound divergence; RE-depth = referring-expression depth.

- **ATOM-Bench, 2606.16826 (BAAI/PKU) [full text].** Real robot (Franka plus Cobot Magic). The Composition Set has 12 held-out tasks per platform, each combining motor atoms with at least 2 instruction atoms. No systematic split procedure is given. CD is neither measured nor controlled, and MCD/Keysers are not mentioned. One instruction atom, "source_relation", covers relations (e.g. "objects to the left of a cylinder"), but depth is not a factor. Roles appear only as dual-arm hand role and goal_destination. Models: Pi0.5, LingBot-VLA, GR00T N1.6, SmolVLA, Motus. Pi0.5 has an Atomic Score of 83.3% / 79.5% but compositional SR of only 15.8% / 16.7%. Motor, reference and timeout failures make up over 90% of failures. It defines a Compositional Failure Share (CFS) metric. — [ATOM-Bench](https://arxiv.org/html/2606.16826)
- **RoboHiMan / HiMan-Bench, 2510.13149 [full text].** 114 atomic and 144 compositional task instances, on progressive training levels L1-L4 (atomic, plus perturbed atomic, plus 4 compositional, plus perturbed compositional). Testing uses 12 compositional tasks, 4 seen and 8 unseen. No CD. Perturbations separate manipulated-object from receiver-object attributes, which is a perturbation distinction rather than a role/binding study. Drawer words such as top/middle/bottom appear but are not varied systematically. Models: RVT-2, 3D Diffuser Actor, pi0, pi0.5, with a Qwen2.5-VL or rule planner. pi0.5-RP scores 0.105 and pi0-RP 0.065 on L4 to C&CP. Vanilla models without a planner score at most 0.005. — [RoboHiMan](https://arxiv.org/html/2510.13149)
- **RoboCombine = "Exploring the Limits of Combinatorial Generalization in Embodied Manipulation", 2610.15425 (SJTU AutoLab) [full text].** The arXiv ID is confirmed. The HTML does not state a venue, so NeurIPS 2026 is unconfirmed. The benchmark is built on RoboTwin: it trains on 50 isolated atomic tasks and tests 19 unseen two-stage ordered compositions in simulation. The real robot uses Set A (seen), B (partial overlap) and C (unseen). No CD; the split is categorical only. Real-robot prompts contain left/right/center plate references, but these are not a factor. Models: Motus, FastWAM, LingBot-VLA, pi0.5. Full-instruction ordered success is 40.0 / 15.0 / 4.4% on sets A / B / C. The proposed PRTI method reaches 18.16% vs a 2.63% base. The authors blame a "start state gap" at the handoff between stages. — [RoboCombine](https://arxiv.org/html/2610.15425)
- **Diagnosing Compositional Generalization in Sequential Robot Tasks, 2607.29687 (UC Berkeley, Tomizuka) [full text].** Tasks are tuples of discrete factors: object x container (PP, 16 tasks), x button (PPP, 64), and a dependent two-stage 2S-PP (144). OOD = test support minus training support. Training subsets are hand-designed: budget-B sets covering every value, orthogonal sets covering every pair, a diagonal pretraining set, and Cov12/9/6/4 pair-coverage sets. CD is not measured and MCD is not cited. Instead the paper bounds the generalisation gap with three L1 shift terms (marginal, instruction-compositional, context-action). The factors are object, container and button colour; no referring depth or relations. The policy is a custom flow-matching policy with a frozen DINOv2 encoder, not a pretrained VLA. Results: OOD success at B = 4 / 8 / 16 is 0.83 / 23.93 / 82.29% while ID loss stays flat. A 16-task orthogonal PPP set reaches 78.2%, against 78.6% for full-task training. Quote: "pairwise coverage helps explain generalization beyond training-set size alone." — [2607.29687](https://arxiv.org/html/2607.29687)
- **Scale Up Strategically, 2607.21582 (Northeastern/NVIDIA) [full text, partial].** The instruction template is "[Verb] the [Size] [Color] [Object] on the [Spatial Attribute] of the table", over 6,480 instructions. Spatial values include left/right/middle/front/behind. Training correlates two factors (the diagonal) and testing uses the off-diagonal combinations. The metrics are factor-dominance FDR = (N_f1 - N_f2)/(N_f1 + N_f2 + eps) and a Copeland-ranked FDH, both computed post hoc from rollouts. It cites Keysers et al. in related work only and never uses the MCD metric. No left/right frame convention is defined. Models: pi0.5, pi0, OpenVLA-OFT, GR00T-N1.7, X-VLA, Genie-Envisioner. Hierarchy: color >= object >= spatial >= verb >= size. — [2607.21582](https://arxiv.org/html/2607.21582)
- **What Can One Sentence Fix?, 2608.29967 (CMU) [full text].** This is a failure taxonomy over LIBERO-90 for OpenVLA-OFT and pi0.5 fine-tuned on 40 other LIBERO tasks: 133 failing pairs labelled by one annotator. Task misunderstanding is about 47% / 50% of failures, "mainly ... the policy resolves a relative spatial reference in the image frame rather than the table frame". Examples: "the middle bowl" is taken as the middle of the image instead of the middle of the row; for "the back bowl" the policy takes the one on the left. No CD and no splits. The fix (CorrectVLA) is an additive, time-windowed action bias that only addresses execution misalignment. The words mirror/flip never appear. — [2608.29967](https://arxiv.org/html/2608.29967)
- **Robust Skills, Brittle Grounding, 2602.24143 (Naver Labs) [full text].** ManiSkill, 5 YCB objects, a single template "grasp the <object>". The compositional split trains each object in 3 of 5 regions and holds out 2. Every atom is seen and only the pairings are new, which is an implicit atom-preserving split, though CD is not measured. Results for SmolVLA: 44% success on ID pairings vs 0% on held-out pairings, with reach 100% vs 2%. pi0.5 was tested only in jitter/random regimes. No RE-depth, relations or roles. — [2602.24143](https://arxiv.org/html/2602.24143)
- **RoboSemanticBench, 2606.02277 [full text].** The robot must answer math or knowledge multiple-choice questions by grasping the lettered block for the answer. Train and eval questions are disjoint. The metric is nSG = (TSR/GSR - 1/N)/(1 - 1/N). No CD, depth, relations or roles. Models: OpenVLA-OFT, GO1, DexVLA, TinyVLA, PD-VLA, pi0, pi0.5, GR00T N1.7, QwenGR00T. Most models have nSG at or below 0, i.e. random or worse target selection. pi0.5 is best, with nSG 5.2. — [RoboSemanticBench](https://arxiv.org/html/2606.02277)
- **Spa-Bench, 2610.12696 (Imperial) [full text].** This is the closest design. A concept-argument matrix is built; observed cells are ID and withheld cells are OOD, and "each withheld cell's components still appear elsewhere in training". This preserves atoms, but CD is neither measured nor graded. Grounding axes are attribute, relation (Relational Placement, Referential Description) and scene structure (ordinal, counting). There is no depth or sub-region factor, and roles are only implicit (target vs reference). The frame is explicitly robot-centric: "All directional and ordinal descriptions are defined from the robot's perspective ... rather than directions relative to an individual camera view." Models: MolmoAct2, pi0.5, GR00T-N1.7, with partial results for VLA-0. OOD success is 52.0 / 44.3 / 40.7% vs 81.7-89.2% on matched direct-manipulation instructions. All three models fail every OOD Counting rollout. — [Spa-Bench](https://arxiv.org/html/2610.12696)
- **RefSpatial-Bench (RoboRefer), 2506.04308 [full text, partial].** 200 real images in Location and Placement subsets. Over 70% of items need multi-step reasoning, up to 5 steps. There is an "unseen" subset of 77 items with new combinations of spatial relations. Results are not stratified by step count, and no VLA is evaluated on it; the models are VLM pointers such as Gemini-2.5-Pro and RoboRefer. The left/right frame is not defined and looks camera-based ("third cup from the left"). — [RoboRefer](https://arxiv.org/html/2506.04308)
- **VIMA-Bench, 2210.03094 [full text, partial via ar5iv].** L1 placement (prompts seen verbatim), L2 combinatorial (seen textures and objects in new combinations), L3 novel objects/textures, L4 novel task templates. No CD measurement; L2 is a binary "new combination" level. — [VIMA ar5iv](https://ar5iv.labs.arxiv.org/html/2210.03094)
- **GemBench, 2410.01345 [full text, partial].** L1 new placements, L2 new rigid objects (20 new object-colour combinations, 8 shapes), L3 new articulated objects (8 new action-part combinations, e.g. a drawer part not seen in training), L4 long-horizon. No CD. Spatial language is not a factor. Models are 3D policies (Hiveformer, PolarNet, 3D Diffuser Actor, RVT-2, 3D-LOTUS/++), not VLAs. Note that the L3 "action-part" combinations are a sub-region-like factor, but they are a novelty level and not a referring-depth axis. — [GemBench](https://arxiv.org/html/2410.01345)
- **AGNOSTOS, 2505.15660 [full text].** RLBench, 18 seen and 23 unseen tasks. Level-1 unseen tasks share objects or motions with seen tasks; Level-2 share neither. The levels were categorised by GPT-4o and checked by humans. No CD, relations or depth. Models include OpenVLA, RDT, pi0, SAM2Act and others, and the paper's X-ICM. — [AGNOSTOS](https://arxiv.org/html/2505.15660)
- **CompoSuite, 2207.04136 [full text via ar5iv].** 4x4x4x4 = 256 RL tasks (robot x object x obstacle x objective). Uniform sampling trains on 56 or 224 tasks; "restricted" sampling sees only one task containing a given element. No CD. Compositional-agent zero-shot success is about 0.88 with 224 training tasks vs about 0.08 with 56. — [CompoSuite](https://ar5iv.labs.arxiv.org/html/2207.04136)
- **LIBERO-PRO, 2510.03827 [full text].** Perturbs objects, initial configurations, instructions, tasks and environments, each with a bounded magnitude plus a total-variation threshold. No CD, depth, relations or left/right. Models: OpenVLA, pi0, pi0.5. Corrupted instructions leave trajectories almost unchanged. — [LIBERO-PRO](https://arxiv.org/html/2510.03827)
- **LIBERO-Plus, 2510.13626 [full text, partial].** 7 perturbation dimensions, 10,030 tasks. Section 5 defines a "compositional generalization gap" Δij = Aij − Aji over pairs of perturbations; this is perturbation composition, not instruction-compound divergence. No depth or roles. OpenVLA-OFT scores 97.1% originally, 59.7% under camera perturbation and 37.2% under robot-state perturbation. Models are "largely insensitive to language variations". — [LIBERO-Plus](https://arxiv.org/html/2510.13626)
- **Adjacent work, VLM only, not VLA:** "Referring Expressions as a Lens into Spatial Language Grounding", 2511.06146 [full text], does stratify by number of spatial relations (0/1/2/3, plus chained/and/or). Accuracy drops with depth for most VLMs; DeepSeek-VL2 goes 41.1 → 11.1. The compositional MGA-Net is flat (62.4 → 65.2). — [2511.06146](https://arxiv.org/html/2511.06146)
- **One Word, Different Action, 2609.05260 [full text].** Composition of logical operators (inhibition, exclusion, cardinality, ordering), evaluated only on LLMs. No splits, CD or relations. — [2609.05260](https://arxiv.org/html/2609.05260)
- A search for "compound divergence" together with robot or VLA returned no robot paper that uses it. — [search, abstract/snippet]

### Inferences
Verdict per sub-claim:
- **(a) MCD-style splits with atom divergence fixed and compound divergence binned at 0.1/0.3/0.5 for robot instruction binding: NOVEL.** None of the 17 works reads measures or controls CD. The nearest are held-out-cell / off-diagonal splits (Spa-Bench, 2607.21582, 2602.24143), which sit at a single, unmeasured CD point, and pair-coverage sweeps (2607.29687), which act as a monotone proxy.
- **(b) Stratification by referring depth (type / instance / relational sub-region) and by role: NOVEL for VLAs.** Spa-Bench and ATOM-Bench include relational instructions but do not grade depth. 2511.06146 shows that error rises with depth in VLMs, which is useful supporting prior work and should be cited, but it does not test VLAs or actions.
- **(c) Evidence that binding error in VLAs and existing fixes rises with depth: NOVEL as a measured curve.** Indirect support: 2608.29967 attributes about half of pi0.5's LIBERO-90 failures to spatial-reference misreading, and Spa-Bench's relational and counting OOD scores sit far below its direct-manipulation scores.
- **(d) Theory-predicted ablation outcomes: partially pre-empted.** 2607.29687 gives a theoretical L1-shift bound on the generalisation gap that relates to compositional shift, but it is not used to predict ablations, and its policy is a custom one rather than a pretrained VLA.

### Gaps
- VIMA, GemBench, LIBERO-Plus and RefSpatial were read only to about 100k characters. Their late appendices (e.g. the VIMA task list and the RefSpatial step-count breakdown) were not checked for depth tables.
- RoboCombine's venue (NeurIPS 2026) could not be confirmed from the arXiv HTML.
- I did not search OpenReview for NeurIPS 2026 or ICLR 2027 submissions that might add MCD splits but are not on arXiv.

## Q2. Has anyone reported that LIBERO's left/right words are mirrored relative to the flipped policy image, or that camera-frame and robot-frame lateral words get confused?

### Takeaway
I found no report that LIBERO's lateral instruction words are mirrored relative to the image the policy sees. What I did find:
- The ingredients are documented. openpi rotates agentview 180°. Show-Harness (merged 2026-09-30) explicitly notes that a vertical flip and a 180° rotation differ by a horizontal mirror, with world +y on opposite sides of the screen.
- 2608.29967 reports VLAs resolving spatial references "in the image frame rather than the table frame" on LIBERO-90.

Nobody connects the two. The specific gotcha appears unreported, but it is a short step from public material, so frame it as a caveat or finding rather than a headline.

### Cited Findings
- openpi's LIBERO eval preprocesses images with `# IMPORTANT: rotate 180 degrees to match train preprocessing`, applying `obs["agentview_image"][::-1, ::-1]` and the same to the wrist image. — [openpi examples/libero/main.py](https://raw.githubusercontent.com/Physical-Intelligence/openpi/main/examples/libero/main.py) [full text]
- Show-Harness PR #4 (merged 2026-09-30) [full text] quotes:
  - "Upstream un-flips it with `obs[cam][::-1]`, a vertical flip; this contract rotates 180° instead. Both stand the scene upright, but they differ by a horizontal mirror"
  - "under `[::-1]` world +y moves left on screen, under the rotation it moves right."
  - "`MV_RIGHT` has to look like right to the policy, so the rotation wins."
  - "our frames are mirrored relative to upstream figures."

  The PR does not discuss instruction words. — [Show-Harness PR #4](https://github.com/showlab/Show-Harness/pull/4)
- SimonReese/play-libero notes that robosuite images follow the OpenGL layout and that OpenPi/OpenVLA flip both axes. — [play-libero](https://github.com/SimonReese/play-libero) [abstract/snippet]
- The LIBERO repo has 6 issues matching "flip". #11 ("Flipped demonstration images", 2023) and #14 ("Image rendering issues", 2024: upside-down frames, agentview returning the in-hand view) describe vertical flips only. None mention a horizontal mirror or left/right. — [GitHub API search, LIBERO](https://api.github.com/search/issues?q=repo:Lifelong-Robot-Learning/LIBERO+flip) [full text of listing]
- openpi issues matching flip/mirror/180/upside down: none concern LIBERO image orientation. #602 is a joint sign-flip mask. — [GitHub API search, openpi](https://api.github.com/search/issues?q=repo:Physical-Intelligence/openpi+flip+OR+mirror+OR+180+OR+%22upside+down%22) [listing, partial]
- lerobot: no matching LIBERO flip or mirror issue. — [GitHub API search, lerobot](https://api.github.com/search/issues?q=repo:huggingface/lerobot+libero+flip) [listing]
- dreamzero issue #39 reports that LIBERO dataset videos and sim observations are vertically inverted. — [dreamzero #39](https://github.com/dreamzero0/dreamzero/issues/39) [abstract/snippet]
- 2608.29967 says pi0.5 and OpenVLA-OFT on LIBERO-90 "resolve[] a relative spatial reference in the image frame rather than the table frame". For "the back bowl", the policy takes the one on the left. — [2608.29967](https://arxiv.org/html/2608.29967) [full text]
- Spa-Bench defines all directions from the robot's perspective, "rather than directions relative to an individual camera view". This shows the camera-vs-robot frame ambiguity is recognised as a design choice; it is not reported as a LIBERO bug. — [Spa-Bench](https://arxiv.org/html/2610.12696) [full text]
- LIBERO-Plus perturbs the camera but does not mention mirroring or left/right ambiguity. — [LIBERO-Plus](https://arxiv.org/html/2510.13626) [full text, partial]

### Inferences
- **Verdict on "LIBERO lateral words are mirrored relative to the policy image": APPEARS UNREPORTED. Confidence is moderate.** Searched sources: the LIBERO, openpi and lerobot issue trackers, plus web search.
- The 2608.29967 "image frame vs table frame" observation could partly be produced by this convention, which would make the finding sharper. It is worth citing: they describe the symptom, and we can explain its cause.
- Before claiming it, verify against the BDDL world coordinates which world axis LIBERO's "left" names, and whether the training-data images were stored with the same flip as the 180° rotation openpi applies at eval. openpi's comment says the rotation matches training preprocessing, so the mirror would have to exist in the policy image itself relative to the words.

### Gaps
- GitHub full-text issue search for openvla, openvla-oft and LIBERO-PRO/Plus forks was not run, because the gh CLI is unavailable and the unauthenticated API was rate-limited in practice. Discussion threads and Discord/Slack channels were not searched.
- Not checked: whether LIBERO's original paper or BDDL documentation defines left/right as robot-frame or viewer-frame.

## Q3. Does any work predict compositional success from component measures before rollout?

### Takeaway
No VLA work predicts compositional or binding success from component measures before rollout. ATOM-Bench, RoboCombine and One Word Different Action all report that atomic success does not predict compositional success. Only a SAC-module regression-testing paper (2604.26689) uses per-module probes to screen compositions ahead of time, and only in clear-cut cases. 2607.29687 offers a bound and a correlation with coverage, not a prediction.

### Cited Findings
- ATOM-Bench treats Atomic Score as an "atomic-baseline ceiling". Pi0.5 shows a large gap (AS 83.3% vs compositional SR 15.8%), so AS does not forecast composite success. — [ATOM-Bench](https://arxiv.org/html/2606.16826) [full text]
- RoboCombine: "high first-stage completion does not reliably convert into downstream success". This is examined qualitatively, with no predictive model. — [RoboCombine](https://arxiv.org/html/2610.15425) [full text]
- 2607.29687 gives a theoretical bound built from three L1 shift terms. Empirically, OOD success rises with the number of seen instruction pairs, but no predictive model is fitted. — [2607.29687](https://arxiv.org/html/2607.29687) [full text]
- 2604.26689 (Regression Test Selection via Atomic-Quality Probes; SAC modules for reach/grasp/lift/place in robosuite, not VLAs):
  - The probe is each module's solo success, q(c).
  - A Hybrid Selector accepts or rejects updates from the probe gap and falls back to rollout when the gap is small.
  - Pooled r = 0.94 over 33 weight-interpolation points, which the authors call descriptive because the points are serially dependent.
  - The selector's advantage over full revalidation is not significant (McNemar p = 0.25).

  — [2604.26689](https://arxiv.org/html/2604.26689) [full text, partial]
- 2607.21582's FDR/FDH metrics are computed from rollouts, i.e. post hoc. — [2607.21582](https://arxiv.org/html/2607.21582) [full text, partial]
- One Word, Different Action: "Atomic correctness does not guarantee compositional correctness" (LLMs only). — [2609.05260](https://arxiv.org/html/2609.05260) [full text]

### Inferences
- **Verdict on "theory-predicted ablation outcomes / predicting binding error from component measures before rollout": NOVEL for VLAs.** The field's prevailing message is that atomic scores fail to predict composition. A positive pre-rollout prediction would therefore stand out, and it needs to beat the obvious baseline "composite = product of atomic success rates".
- **Strongest reviewer objection:** "Your compound-divergence bins and referring-depth strata are confounded with each other and with visual difficulty. Deeper references need more objects and finer localisation, and high-CD splits put rarer atom co-occurrences into training. The error rise could therefore be perception or data volume rather than binding. Spa-Bench and 2602.24143 already show held-out pairings fail at a single CD point, and 2607.29687 already shows coverage explains OOD success; MCD binning just re-parameterises that." A secondary objection: the LIBERO lateral mirror may itself produce the 'relational' errors, so depth-stratified results on LIBERO must control for the frame first. Pre-empt both:
  - Match visual scenes across depth strata, so the same scene is used with type, instance and sub-region references.
  - Report CD alongside 2607.29687-style pair coverage, to show CD adds predictive power beyond coverage.
  - Fix or flip the lateral words before measuring.

### Gaps
- I did not find whether any 2026 work fits a regression from per-factor grounding accuracy (e.g. Spa-Bench's per-axis scores) to compositional success. None appeared in the searches.
- The 2604.26689 limitations section was truncated.
