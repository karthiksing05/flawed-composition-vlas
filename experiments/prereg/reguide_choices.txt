ReGuide reimplementation: what the paper specifies (implemented) and the simplest readings chosen where it does not (deviations). Written before any main rollout. Sources: arXiv 2609.38616v1 HTML (main method, Algorithm 1, App. A.4-A.7, B, C.6, C.7, Table 5); no code was released.

IMPLEMENTED AS SPECIFIED
S1 Frozen policy, unchanged prompt and images; pi0.5 chunk 10, 5 executed per query (App. B; = our harness).
S2 Statistics from the training demonstrations only (here the raw LIBERO-Goal demos of trained tasks K1-K6; never N1-N6), at Table 5's quantile levels: grasp offset and entry altitude Q.5; rotation medoid; tau_R, r_e, s, s_R, dwell, release duration Q.95; commitment radius rho_e Q.25 of the box-surface distance at entry; carry radius Q.25 of the object-destination distance during carries; release offset and release height Q.5; height profile m_f Q.5 and lower envelope Q.05 in 2 cm bins (>= 20 samples per bin, >= 10 demos per class); kappa = median realized / commanded motion.
S3 Constants: n = 3, N = 40 (75 after a completed clause), eps = 4 mm, transport budget 2 per stage, 10 idle steps (A.7).
S4 Predicted endpoint (Eq. 2) from the unexecuted chunk scaled by kappa * sigma; posture by composing the rotations.
S5 Commitment (Eq. 3): endpoint inside the candidate's box along two axes, the remaining offset < rho_e and smaller than the current one; the policy's referent = the committed candidate nearest the endpoint. Mismatch: referent != instructed, moving point outside rho of the instructed box, no contact.
S6 Triggers: wrong binding; posture mismatch before descent (predicted error > tau_R and not improving on the current by more than s_R); failure to bind (N steps without one demonstrated step of progress in position, posture or gripper closing); destination mismatch needs n consecutive verdicts, dwelling at a habitual destination counts immediately.
S7 Pre-contact target (Eq. 4): object centre + canonical-frame median grasp offset, z = top + median entry altitude, orientation = canonical frame x rotation medoid; rotationally symmetric objects use the up axis only (A.6).
S8 Pre-contact set K_e (Eq. 5): within one translation step, lateral error <= r_e, posture error (modulo the gripper half-turn) <= tau_R.
S9 Bounded command (Eq. 6) in the policy's own delta action space: u = D/|D| min(|D|, s)/(kappa_p sigma_p), w = axis min(angle, s_R)/(kappa_R sigma_R); gripper open on approach, closed (at rest) while carrying.
S10 Hand-back: the pending chunk is discarded and the policy queried on the true observation; no policy query while ReGuide steers.
S11 Carry: lift-then-translate, height following m_f floored by the crest of the lower envelope; masked classes (cabinet-top side, wine rack) keep the current height and the policy places; hand-back one step above release height inside Omega_d.
S12 Dissolution on a premise change (grasp / drop) or no error decrease > eps over n replans.
S13 Completion certificates: re-arm when the held object leaves Omega_d for n steps after a transport; stall N; dwell outside Omega_d within the carry radius > Q.95 dwell; dwell inside Omega_d without descent > Q.95 dwell -> descend to the Q.5 release height and open within the release duration. The second transport of a stage only on a certificate.
S14 Algorithm 1 step 6: the policy's action is clamped to the demonstrated envelope (per-step translation s, rotation s_R).
S15 Oracle interface (App. B): referent identities from the cell specification, poses and extents from simulator state (arm rgo).
S16 Perception (C.6): registration once at instruction time from RGB-D, positions by depth back-projection, no visual tracking afterwards, no oracle fallback (arm rgp).

DEVIATIONS (simplest readings; unspecified or not transferable)
D1 Perception module: our learned segmenter sc_seg + rendered depth + camera calibration (sc_pu.Estimator, calibrated on trained-task demos) instead of GroundingDINO-tiny; fixture sites from sc_pu calib (training-demo constants or mask centres). The task asked for this.
D2 rgp's interaction state is ProprioHeld (finger width, command, lift) because C.6 does no tracking; the held object then follows the hand rigidly from the hold onset; a released object stays where the hand left it. rgo's state is from the simulator (D18).
D3 Habitual set: the paper retrieves the nearest training scene with ResNet-50 on the first frame. All LIBERO-Goal training tasks share our one scene, so retrieval is not run: habitual objects = every movable object, habitual destinations = every LIBERO-Goal goal region / body (plate, bowl, stove, cabinet top, wine rack, drawer, stove front) minus those named in the instruction.
D4 Declared geometry: object extents from the asset meshes (body-frame AABB at rest), since robosuite's top_offset / horizontal_radius are placeholders for these assets. Boxes are footprint rectangles in the canonical frame (world axes for round objects); top fill is not computed; the one type without grasp demos (plate) inherits from the nearest type by log(height, two widths).
D5 Demo events: entry = the start of the run of frames inside the box along two axes that contains the last closing command before the effect (the very first two-axis crossing happens high above the bowl and cheese); release = the first opening command after the effect; engagement's 8-frame co-motion window is not used for the statistics (the effect onset defines the carry).
D6 Destination statistics are pooled per destination class over objects, with heights expressed as the object's bottom (centre + declared bottom offset), so a cream cheese uses the plate's release height measured on bowls; release offsets in the fixture / body frame.
D7 Predicted endpoint uses every unexecuted action of the returned 10-action chunk (not only the 5 that will run).
D8 Omega_d = a disc around the median release offset with radius Q.95 of the release scatter (the paper's "range intersect scatter" is not defined further); dwell = frames inside Omega_d while held before the release; release duration = frames from the opening command to 95% of the finger opening.
D9 Height-floor crest is taken between the destination and the object's current distance (the paper: "the nearer of the object or the first peak of m_f").
D10 Posture during a carry transport holds the orientation at transport onset (unspecified).
D11 Not implemented (not specified enough to reproduce): descent lateral correction and "immediate escort" of the post-hand-back assistance (C.7; the paper's targeted control without them loses 9.9 points), the yaw-hover rise, the destination-specific slice preference beyond same object type, the up-axis rest-class dissolution, and A.4's five-state detector beyond free / attached.
D12 At a hand-back the step that ends the transport holds position (gripper unchanged) and the policy is queried on the next observation, one step later than the paper's immediate query (libero_client queries only at the top of its loop).
D13 Kappa uses sigma_p = .05 m, sigma_R = .5 rad (LIBERO's OSC_POSE limits); our kappa (.242, .225) is close to the paper's (.237, .211).
D14 A stable grasp for a carry transport = finger width within 1 mm over n steps ("at rest", threshold ours) and inside the demonstrated carry-start band [Q.05, Q.95] widened by eps.
D16 Destination commitment (A.5: Eq. 3 on the held object's predicted horizontal position): a destination's box is a movable body's declared mesh footprint or a fixture region's hand-set footprint radius (fa1_common.SIZE: stove .09, cabinet top .10, rack .10, drawer .10, stove front .04 m); rho for destinations = that class's Q.25 carry radius (classes without carry demos, drawer and stove front, take the median). Dwelling = the current held position satisfies the same test (offset below the carry radius, no approach condition) and moved < eps over n steps.
D17 Masked classes: "transport keeps current height there" read as the transport's height target = the height at transport onset, still floored by the demonstrated crest (lift-then-translate), with hand-back on entering Omega_d.
D18 rgo's interaction state: attach at the effect onset with the object within 12 cm of the hand; detach when the object's hand-frame offset drifts > 2 cm from its value at attachment (end of co-motion); rest height re-taken after a detach.
D15 After a release outside Omega_d the object stage re-arms (approach again) under the stage's remaining budget.
