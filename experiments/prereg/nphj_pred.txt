New arms, evaluated on the same 7th set (k 880-939; no new set): Phase A N1-N6 + K1-K6, 60 states per task.
Arm 1, A0-24k: pi0-A0's recipe (pi0_g8v_raac_l_ae, data, norm, init, batch 32, lr 5e-5 with warmup 1,000; the config's cosine schedule has decay_steps 1,000,000 and decay_lr = peak, so it is constant after warmup and is not changed) trained 24,001 steps instead of 6,001.  Seeds 42, 43 (exp t24k_s<seed>).  Tests under-training.
Arm 2, J: a jointly trained where-branch on pi0 (pi0_g8v_raaj_l_ae, lifelong_ood/policy/raaj_model.py).  MLP 3 -> 64 -> 64 -> 30 (SiLU) reads the same token input as H* (object-to-target offset = un-normalised state[:3], role gate m = 1 iff role id > 1.5,

no distillation, no fixed form (no tanh, no clip).  Last layer zero-initialised, so J = 0 at step 0.  6,001 steps, recipe otherwise identical to pi0-A0.  Seeds 42-45 (exp tj_s<seed>).
Pre-training checks (nphj_check.sh; the J training links exit 0 unless results/flawed/nphj7/checks_ok.marker exists): step-0 J = pi0-A0 (sample and loss equal < 1e-6, J output exactly 0); 30-step smoke training; export parity jax vs torch < 1e-4 on 100 states; exported tensors equal the JAX checkpoint.
Gates: K1-K6 mean < .70 for a (arm, seed): that seed is UNTESTABLE and dropped.  Fewer than 3 valid J seeds: j1, j2, jK UNTESTABLE.
Hierarchical bootstrap (every interval below): resample seeds with replacement within each arm (independently per arm, among the arm's valid seeds; the comparators use all four seeds), then states within each task (one resample per task, shared by the two arms, tasks fixed);
B = 2000, np.random.default_rng(0); 95% percentile interval; point = mean over the arm's valid seeds of the task-mean success difference.
